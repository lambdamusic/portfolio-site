Mac Menu Bar for Dimensions

#python #research-analytics #tool

A Mac menu bar application that makes it quicker to access Dimensions.ai.

Features:

  • Search Dimensions using your clipboard contents
  • Resolve common object identifiers (eg DOIs, Pubmed IDs Dimensions IDs)
  • Shortcuts to landing pages for research categories (FoRs, SDGs etc..)

Installation: grab the latest release from GitHub

Note this is an experimental Dimensions tool that I made in order to test out rumps, a Python library for creating menu bar apps.
