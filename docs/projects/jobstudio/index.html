Job Studio

An agent-native job-search toolkit, run from Claude Code, with a Django web app for browsing the search

Years
2026
Status
Active
Role
Design and development

GitHub ↗

Job Studio is a job-search toolkit that runs inside a Claude Code session. You track the companies you'd like to work for, log the roles you apply to, tailor a CV and a cover letter for each one, prepare for interviews, and scan the companies' job boards for new postings. Every step is a /jobstudio command, and a small Django web app makes the whole search browsable: what's outstanding, what went quiet, what you said to whom.

I built it during my own job search, partly to stay on top of it and partly as an experiment in agent-native software. Most of what decides how it behaves isn't code. How a CV gets tailored, how a posting is scored, what a cover letter sounds like: each is a markdown file that Claude reads, and that you're meant to open and argue with. If the scoring rubric is wrong for your field, you rewrite it.

A few other choices shaped it:

  • No API key. Every workflow, CV tailoring and scan scoring included, runs in your Claude Code session. Even the web app's chat panel drives Claude Code rather than calling a model.
  • Your data stays separate. CVs, applications and notes live in a folder of your choosing, outside the code, as plain markdown and sqlite.
  • It reads the job boards for you. One command rescans every tracked company across Greenhouse, Lever, Ashby, Workable, Workday and more, filters by location, and scores what's left against what you're after. Nothing goes into the tracker until you say so.

The screenshots show the web app running on the example job search that ships with the code.

Technology

  • Claude Code: a skill with one subcommand per task, plus headless runs from the web app
  • Python and Django, with sqlite
  • python-docx for the CV and cover letter exports
  • ECharts for the charts
