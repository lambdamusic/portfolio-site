Interactive English rendition of 'A Dream in Venice', a children book from Štěpán Zavřel originally written in Italian.

Just a little fun project I did in order to be able to read this wonderful story to a bunch of seven year olds.

I had the original hardcopy of the book, which is truly a little work of art. But couldn't find an English version online so I resorted to google translate to bootstrap a new version, then edited it manually to make it more fluent. The end result is not perfect, but it worked for getting the attention of the kids!

Website is a simple Django app that renders the book one page at a time, from a markdown file and static images.

Technology

  • Python and Django
  • Markdown source and static images
