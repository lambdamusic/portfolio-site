Impromptu language browser

A searchable index of the functions for the Impromptu / Extempore programming languages

Years
2015
Status
Completed
Role
Design and development

View the application: Impromptu ↗ View the application: Extempore ↗ GitHub ↗

Impromptu is an OSX programming language and environment for composers, sound artists, VJ’s and graphic artists with an interest in live or interactive programming.

As part of its original website, Impromptu included a wiki with functions documentation and examples. Since the wiki isn't available online anymore, I've created a simple searchable website with (roughly) the same contents (based on the latest Impromptu release: 2.5).

For all Impromptu fans!

2016-01-26: update for Extempore

The same type of documentation is now available also for Extempore, the latest incarnation of the impromptu livecoding environment. Check it out here.
