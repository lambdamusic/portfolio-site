Dimensions API LAB

Open source Jupyter notebooks showing how to carry out common research data analytics tasks using the Dimensions Analytics API.

The API LAB is a collection of open source Jupyter notebooks showing how to carry out common research data analytics tasks using the Dimensions Search Language (DSL) API.

The Dimensions API provides full-text search and data retrieval for use in complex analyses and visualizations. The API uses an intuitive query language specifically developed for Dimensions data. You can retrieve, aggregate, and sort data from highly specific requests in a single API call. Additional services like text categorization are also available, allowing you to efficiently classify and interpret large datasets based on your unique requirements.

Key features of the LAB:

  • Python notebooks demonstrating applications of the Dimensions API for research data analytics e.g. Competitive intelligence, Identifying emerging research activity, Key Opinion Leader (KOL) identification etc..
  • All notebooks developed so that they work out-of-the-box with both standard Jupyter and Google Colab environments
  • API Lab website generated dynamically from a collection of notebooks, thanks to NBSphinx

Technology

  • Python Jupyter notebooks, for Jupyter and Google Colab
  • Dimensions Analytics API (DSL)
  • Sphinx and NBSphinx for the website
