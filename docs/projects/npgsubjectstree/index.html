Taxonomy Visualizations

A collection of D3 visualizations for the nature.com taxonomy of scientific subjects

Years
2014
Status
Completed
Role
Design and development

View the application ↗

These days there are a lot of browser-oriented visualization toolkits, such d3.js or jit.js. They look great and are easy to use, but how much do they scale when used with medium or large hierarchical datasets?

This application was created to test some of these visualization frameworks in particular by attempting to display the nature.com 'subject ontology' - a quite large (~2500 concepts) multi-hierarchical taxonomy made available by Nature Publishing Group in order to describe the topic(s) of a scientific publication.

Technology

  • D3.js and the JavaScript InfoVis Toolkit
