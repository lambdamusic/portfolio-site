Event: Installation at Sydney Data Arena

#event #travel

My piece, "Dreamy Pianos - Study No 1 in C Minor," is part of a new sonic installation by Simon Porter, currently showcased at the University of Technology Sydney.

The installation took place on March 4, 2025, as part of the Digital Science Showcase within the UTS DataArena. The installation, titled Australian Institution Co-authorship Collaboration Patterns, was developed by Simon Porter and represents a network of co-authored researchers affiliated with Australian institutions from 2018-2023.

Each researcher has been color-coded by the scientific field code they are most associated with. Each researcher is depicted by a sphere and given a size based on the number of publications produced. More information is available on the installation's Figshare page.

Find out more about my piece: Dreamy pianos - Study No 1 in C Minor.
