Recent projects from CrossRef.org

We spent the day with the CrossRef team in Oxford last week, talking about our recent work in the linked data space (see the nature ontologies portal) and their recent initiatives in the scholarly publishing area.

So here are a couple of interesting follow-ups from the meeting. P.S. If you want to know more about CrossRef, make sure you take a look at their website and in particular the labs section: http://labs.crossref.org/.

Opening up article level metrics

http://det.labs.crossref.org/

CrossRef is using the open source Lagotto application (developed by PLOS https://github.com/articlemetrics/lagotto) to retrieve article metrics data from a variety of sources (e.g. wikipedia, twitter etc. see the full list here).

The model used for storing this data follows an agreed ontology containing for example a classification of 'mentions' actions (viewed/saved/discussed/recommended/cited - see this paper for more details).

In a nutshell, CrossRef is planning to collect and make available the raw metrics data for all the DOIs they track in the form of 'DOI events'

An interesting demo application shows the stream of DOIs citations coming from Wikipedia (one of the top referrers of DOIs, unsurprisingly). More discussions on this blog post.

Linking dataset DOIs and publications DOIs

http://www.crosscite.org/

CrossRef has been working with DataCite with the goal of harmonizing their databases. DataCite is the second major register of DOIs (after CrossRef) and it has been focusing on assigning persistent identifiers to datasets.

This work is now gaining more momentum as DataCite is enlarging its team. So in theory, it won't be long before we see a service that allows us to interlink publications and datasets, which is great news.

Linking publications and funding sources

http://www.crossref.org/fundref/

FundRef provides a standard way to report funding sources for published scholarly research. This is increasingly becoming a fundamental requirement for all publicly funded research, so several publishers have agreed to help extract funding information and send it to CrossRef.

A recent platform built on top of FundRef is Chorus http://www.chorusaccess.org/, which enables users to discover articles reporting on funded research. Furthermore, it provides dashboards which can be used by funders, institutions, researchers, publishers, and the public for monitoring and tracking public-access compliance for articles reporting on funded research.

For example see http://dashboard.chorusaccess.org/ahrq#/breakdown

Miscellaneous news & links

- JSON-LD (an RDF version of JSON) is being considered as a candidate data format for the next generation of the CrossRef REST API.

- The prototype http://www.yamz.net/ came up in discussion; it's a quite interesting Stack Overflow-meets-ontology-engineering kind of tool. Definitely worth a look, I'd say.

- Wikidata (a queryable structured data version of Wikipedia) seems to be gaining a lot of momentum after taking over Freebase from Google. Will it eventually replace its main rival DBpedia?
